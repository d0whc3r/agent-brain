# Obsidian

Install the Local REST API plugin in Obsidian. Enable its MCP endpoint.

Copy the MCP URL into `mcp/snippets/obsidian.url`.

Copy the API key into `mcp/snippets/obsidian.key`.

Both files are gitignored. Do not commit them.

Do not register the Obsidian MCP until both files exist.

The agent adds and deletes premises only through `brain premise` or the premise MCP.
