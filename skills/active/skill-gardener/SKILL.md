Read open notes in memory/decisions and active premises in memory/premises.

Cluster notes that share a repo and a rule.

Draft one skill when three similar premises share that rule. One always or never correction stays a premise until that count is met, or until Josep asks for a skill.

Create skills/drafts/<name>/SKILL.md for the draft.

Set each used decision status to drafted. Write a pattern note that links to the draft.

Stop after the draft. Do not edit skills/active. Do not commit. Do not push.
